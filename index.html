Formulaire d'Analyse de Données Statistiques

Analyse Univariée & Bivariée — Formules Exhaustives et Explications

1. Statistique Univariée (Une seule variable)

1.1 Moyenne Empirique ($\bar{X}$)

$$\bar{X} = \frac{1}{N} \sum_{i=1}^{N} X_i$$
Explication : Somme de toutes les valeurs observées divisée par le nombre d'observations $N$. Elle représente le centre de gravité des données.

1.2 Médiane ($Me$) et Étendue ($E$)

Étendue : Différence entre la valeur maximale et minimale observée.

$$E = X_{\max} - X_{\min}$$

Médiane : Valeur qui sépare la série ordonnée en deux parties égales (50% en dessous, 50% au-dessus).

$$\text{Si } N \text{ est pair : } Me = \frac{X_{(N/2)} + X_{(N/2 + 1)}}{2} \quad \Big| \quad \text{Si } N \text{ est impair : } Me = X_{\left(\frac{N+1}{2}\right)}$$

1.3 Variance ($\sigma^2$ ou $S^2$) et Écart-Type ($\sigma$ ou $S$)

Explication : La variance mesure la dispersion des données autour de la moyenne. L'écart-type en est la racine carrée et s'exprime dans la même unité que les données d'origine.

Population Globale On dispose de N individus

On divise par $N$ :

$$\sigma_X^2 = \frac{1}{N} \sum_{i=1}^{N} (X_i - \bar{X})^2$$

Écart-type :

$$\sigma_X = \sqrt{\sigma_X^2}$$

Échantillon Extrait d'une population

On divise par $N - 1$ (correcteur de Biais) :

$$S_X^2 = \frac{1}{N - 1} \sum_{i=1}^{N} (X_i - \bar{X})^2$$

Écart-type échantillon :

$$S_X = \sqrt{S_X^2}$$

2. Statistique Bivariée (Deux variables X et Y)

2.1 Covariance ($\sigma_{XY}$ ou $S_{XY}$)

Explication : Mesure le sens de variation conjointe entre deux variables. Une covariance positive indique que les deux variables ont tendance à varier dans le même sens.

Population Globale Divisé par N - 1

$$\sigma_{XY} = \frac{1}{N - 1} \sum_{i=1}^{N} (X_i - \bar{X})(Y_i - \bar{Y})$$

Échantillon Divisé par N

$$S_{XY} = \frac{1}{N} \sum_{i=1}^{N} (X_i - \bar{X})(Y_i - \bar{Y})$$

2.2 Coefficient de Corrélation de Pearson ($r_{XY}$)

$$r_{XY} = \frac{\sigma_{XY}}{\sigma_X \cdot \sigma_Y} \quad \text{ou} \quad r_{XY} = \frac{S_{XY}}{S_X \cdot S_Y}$$
Explication : Normalise la covariance pour obtenir une mesure sans unité comprise entre $-1$ et $1$.
  • $r = 1$ : Corrélation linéaire positive parfaite.
  • $r = -1$ : Corrélation linéaire négative parfaite.
  • $r = 0$ : Absence de relation linéaire.

2.3 Normalisation Min-Max

$$X_{\text{norm}} = \frac{X - X_{\min}}{X_{\max} - X_{\min}}$$
Explication : Transforme les valeurs d'une variable quantitative pour les ramener dans l'intervalle $[0, 1]$.
